# Data model

Normalized activities preserve `tracks`, `segments`, and coordinate points so future derived processors can safely work without joining discontinuities. Full IDs combine a UTC start-time prefix (or `unknown-date`) and the first 12 characters of the byte-level SHA-256 hash. Turtle uses `<#activity>`, Schema.org quantitative values and observations; activities identify the Solid Fit Converter and its application version as the producing software. Units are km, km/h, metres, and seconds. Format-specific parsers feed the model; future FIT/TCX readers and derived-data processors can use the same interfaces.

Each GPX resource and its full Turtle summary live together under `source-files/<year>`. The full summary links to the GPX and retains source names, timestamps, locations, bounds, and unrounded statistics for trusted clients. `activities/<year>` contains a shareable summary instead: its filename and dates expose only the UTC month; its synthetic name contains the exercise type and one-decimal average speed; locations, bounds, and the source link are omitted; distances are rounded to tens of metres, speeds to one decimal place, and elevations to whole metres.
